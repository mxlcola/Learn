@@@@@ 上火 ||| tags=身体健康 中医 ||| 347字
上火，是民间和中医语境中常用来描述火热、炎症样不适、口腔咽喉不适、口臭、便秘、烦躁等表现的说法。它不是一个精确的现代医学诊断。

!! 和牙齿的关系
牙痛、牙龈肿痛、口臭、牙龈脓包等常被说成“上火牙疼”，但要分清：

# 中医可以从[[实火]]、[[虚火]]、[[胃火牙痛]]、[[风火牙痛]]、[[虚火牙痛]]辨证。
# 现代牙科要排查[[龋齿]]、[[牙髓炎]]、[[根尖周炎]]、[[慢性根尖周炎]]、[[牙周炎]]等局部病变。

!! 判断
如果只是短期口腔不适，可观察饮食、睡眠、压力；但若持续牙痛、咬合痛、脓包、面肿或发热，应优先看牙医。

@@@@@ 上火牙疼 ||| tags=上火 牙齿 中医 牙痛 ||| 446字
上火牙疼，是把牙痛归因到饮食辛辣、熬夜、压力、劳累或火热状态的一种常见说法。但从整理角度看，它至少要分成两层：中医证候和现代牙科病变。

!! 中医层面
可以参考[[中医牙痛辨证]]：

# 牙龈红肿热痛、口臭便秘，更像[[胃火牙痛]]或[[实火]]。
# 熬夜劳累后隐隐作痛、反复发作，更像[[虚火牙痛]]或[[虚火]]。
# 突然肿痛、伴外感热象，可参考[[风火牙痛]]。

!! 牙科层面
很多“上火时牙疼”，其实是原本存在的局部病变被诱发或急性发作，例如[[慢性根尖周炎]]、[[牙髓炎]]、[[牙周炎]]、智齿冠周炎等。

典型需要看牙医的表现：牙齿疼痛、咬合痛、牙龈局部脓包、面部肿胀、发热或疼痛持续不缓解。必要时需要拍片检查，而不是只靠清火。

@@@@@ 上颌后牙骨量不足 ||| tags=种牙 上颌窦提升 ||| 327字
上颌后牙骨量不足，是指上颌后牙缺牙区剩余[[牙槽骨]]高度或宽度不够，难以直接提供[[种植体]]稳定植入所需的骨基础。

上颌后牙区容易缺骨，主要有两个原因：

# 缺牙后没有咀嚼刺激，局部[[牙槽骨]]会逐渐吸收变矮。
# [[上颌窦]]可能发生气化，窦腔向下扩大，占用原本可用于种牙的骨空间。

如果剩余骨高度不足，强行植入种植体可能导致初期稳定性差，甚至进入上颌窦腔。因此医生会根据 CBCT 影像评估是否需要[[上颌窦提升]]、[[骨粉]]填充，或考虑短种植体等替代方案。

@@@@@ 上颌窦内提升 ||| tags=种牙 上颌窦提升 ||| 334字
上颌窦内提升，也叫经牙槽嵴顶上颌窦提升，通常用于[[上颌后牙骨量不足]]但缺骨不算特别严重的情况。

基本做法：医生从种植位点的牙槽嵴方向进入，利用器械轻柔抬高窦底黏膜，在下方放入[[骨粉]]，很多情况下可以同期植入[[种植体]]。

特点：

# 创伤相对小，通常不需要从外侧骨壁开窗。
# 提升高度有限，更适合剩余骨高度尚可、只需要少量增加骨量的病例。
# 是否能同期种植，取决于剩余骨高度、骨密度和种植体初期稳定性。

内提升不是“简单版一定更好”，而是适应证不同。骨缺损明显时，可能需要[[上颌窦外提升]]。

@@@@@ 上颌窦外提升 ||| tags=种牙 上颌窦提升 ||| 376字
上颌窦外提升，也叫侧壁开窗上颌窦提升，通常用于[[上颌后牙骨量不足]]较明显、需要增加较多骨高度的情况。

基本做法：医生从上颌后牙区外侧骨壁开一个小窗口，在直视下分离并抬高上颌窦黏膜，然后植入[[骨粉]]。如果剩余骨太薄，可能需要先植骨，等待骨成熟后再植入[[种植体]]。

特点：

# 视野更直观，适合骨量严重不足或提升高度需求较大的病例。
# 创伤和术后反应通常大于[[上颌窦内提升]]。
# 治疗周期可能更长，费用也可能更高。
# 对医生经验、影像评估和术后配合要求更高。

外提升听起来更复杂，但它的目的仍然是同一个：为上颌后牙种植建立足够稳定的骨基础。

@@@@@ 上颌窦提升术后注意事项 ||| tags=牙齿 上颌窦提升 ||| 324字
一句话概括：术后护理的核心是减少出血感染，并避免鼻腔和上颌窦内压力突然升高。

[[上颌窦提升]]术后要保护刚抬高的窦膜和填入的[[骨粉]]。

!! 要点
# 不要用力擤鼻涕；打喷嚏时尽量张口，不要捏住鼻子憋喷嚏。
# 避免用吸管喝饮料、用力吐痰、吹气球等产生负压或高压的动作。
# 短期内避免潜水、剧烈运动和搬重物时憋气。
# 忌烟酒，保持口腔清洁，按医嘱用药和复诊；是否乘飞机、何时恢复运动，按医生根据术式和恢复情况给出的医嘱执行。

如果出现明显鼻腔流液、持续出血、发热、脓性分泌物、剧烈疼痛或肿胀加重，应及时联系医生。

关联：[[窦膜穿孔]]、[[上颌窦内提升]]、[[上颌窦外提升]]、[[植骨粉后注意事项]]

@@@@@ 上颌窦气化 ||| tags=种牙 上颌窦提升 ||| 203字
上颌窦气化是指[[上颌窦]]腔向周围骨组织方向扩大。上颌后牙缺失后，局部骨量减少，上颌窦底可能逐渐向下移，使后牙区剩余骨高度变低。

@@@@@ 中医-牙齿 ||| tags=牙齿 中医 身体健康 ||| 1021字
中医关于牙齿的理论，核心不是把牙齿只看成一个局部器官，而是放进肾、骨、胃经、火热、气血和整体状态里理解。整理时要分清：中医理论适合做整体观察和证候分析；龋齿、牙髓炎、根尖周炎、牙周炎等具体病变，仍需要现代牙科检查和治疗。

!! 一、肾主骨，齿为骨之余
《黄帝内经》中有记载：

>''“丈夫八岁，肾气实，发长齿更。三八，肾气平均，筋骨劲强，故真牙生而长极。五八，肾气衰，发堕齿槁。八八，则齿发去。”''

这条线可以整理为：[[肾主骨生髓]] → [[齿为骨之余]] → 牙齿坚固、松动、枯槁与肾精、骨髓、年龄衰退相关。

!! 二、牙龈与胃火
中医常把牙龈肿痛、口臭、便秘、口渴等表现放到[[胃火牙痛]]里看。简化理解是：牙龈红肿热痛更偏“实热”；隐隐作痛、反复发作、伴阴虚表现，则可能偏[[虚火牙痛]]。

!! 三、牙痛辨证
牙痛不能只用“上火”概括。常见整理入口：

# [[胃火牙痛]]：牙龈红肿、疼痛较剧、口臭口渴、便秘。
# [[风火牙痛]]：牙痛突然、牙龈肿胀、可能伴发热、咽痛或外感表现。
# [[虚火牙痛]]：隐隐作痛、时作时止、夜间或劳累后明显，可伴熬夜、口干、腰膝酸软等。
# [[虫牙与中医牙痛]]：古代“虫蚀牙齿”可对应现代龋齿等局部病变，但不能替代补牙、根管等牙科处理。

!! 四、望诊意义
中医也会从牙齿荣枯、松动、牙龈颜色、肿胀、出血、口气等观察整体状态。可参考[[牙齿望诊]]。

!! 五、古籍材料
如果要看其它医学古籍对牙齿的描述，可从[[古籍中的牙齿描述]]进入，重点包括《灵枢》的阳明经入齿、《诸病源候论》的牙齿病诸候、《备急千金要方》的齿病方、《圣济总录》和《普济方》的口齿门，以及《景岳全书》的火、虫、肾虚三证。

!! 六、现代边界
如果出现持续牙痛、咬合痛、牙龈脓包、面部肿胀、发热、张口困难、吞咽或呼吸困难，应优先看牙医或急诊。中医“上火”只能作为解释框架之一，不能掩盖[[慢性根尖周炎]]、[[牙髓炎]]、[[牙周炎]]、[[龋齿]]等明确口腔疾病。

@@@@@ 中医牙痛辨证 ||| tags=中医 牙痛 牙齿 ||| 520字
中医牙痛辨证，是把牙痛放进风、火、胃、肾、虚实等框架里分析。它适合整理症状模式，但不能替代牙科诊断。

!! 常见分型
# [[胃火牙痛]]：牙痛较剧、牙龈红肿、口臭口渴、便秘，多偏实热。
# [[风火牙痛]]：牙痛突然、牙龈肿胀，可伴外感、发热、咽痛、头痛。
# [[虚火牙痛]]：隐隐作痛、时作时止、劳累或熬夜后加重，常和肾阴不足、虚火上炎相关。
# [[虫牙与中医牙痛]]：古代“虫蚀牙齿”可理解为对龋坏类病变的经验描述。

!! 判断重点
牙痛是否红肿热痛、是否口臭便秘、是否反复隐痛、是否咬合痛、是否有脓包，这些信息决定是偏“火热证候”，还是更像局部牙病急性发作。

!! 现代优先级

@@@@@ 什么时候需要补牙 ||| tags=龋齿 ||| 448字
是否需要补牙，核心看[[牙齿脱矿]]是否已经发展成牙体结构缺损。早期脱矿、[[牙齿白斑]]、牙面完整时，可能优先做[[牙齿再矿化]]管理；但形成龋洞后，牙齿通常不能自己长回去。

常见需要尽快看牙医评估补牙的情况：

# 牙面已经有洞、凹陷或明显缺损。
# 牙线经常在同一位置卡住、起毛或断裂。
# 食物总是塞在同一颗牙或同一牙缝里。
# 牙面发黑、发褐，并伴随粗糙感。
# 冷热甜刺激敏感，或已经出现疼痛。

补牙的意义不是“把洞盖住”而已，而是去除无法再矿化的龋坏组织，并用修复材料恢复牙齿形态，阻止龋坏继续向[[牙髓炎]]发展。

如果拖到牙冠大面积破坏，只剩[[烂牙根]]或没有修复价值的[[残根]]，通常就不再是简单补牙问题，而需要评估根管、桩冠、拔除和后续修复方案。

@@@@@ 口腔感染源 ||| tags=牙齿 口腔 ||| 226字
口腔感染源，是指口腔里''持续存留细菌、坏死组织、脓液或炎性刺激''的部位。它可能暂时不痛，但会反复影响局部牙龈、牙周和根尖周组织。

@@@@@ 口腔菌群 ||| tags=龋齿 ||| 367字
口腔菌群是生活在口腔里的细菌、真菌等微生物群落。每个人口腔里都有大量细菌，关键不是有没有细菌，而是哪类细菌占优势，以及它们是否长期形成牙菌斑。

其中更容易参与龋齿形成的一类细菌，可概括为[[致龋菌]]。它们的共同特点是能利用糖和可发酵碳水产酸，并在牙面生物膜中长期停留。

当产酸细菌在牙面聚集，并不断获得糖或淀粉分解产物时，就会持续产酸，推动[[牙釉质]]脱矿并形成[[龋齿]]。相反，多样且稳定的菌群、足够的[[唾液]]和良好清洁能降低这种风险。

遗传因素也可能影响口腔菌群。AMY1 影响淀粉在口腔里的分解速度，FUT2 影响口腔黏膜表面的糖分子环境，这些都可能改变某些细菌的丰度。

咬合紊乱，是上下牙齿接触关系和受力分布出现异常。它可能来自缺牙、残根长期不修复、邻牙倾斜、对颌牙伸长、牙周支持下降或修复体设计不合适。

在[[烂牙根]]长期不处理时，残根本身没有正常咬合功能，邻牙和对颌牙可能逐渐移动，导致整口咬合关系变乱。

可能表现：

# 咀嚼效率下降。
# 某些牙受力过重、酸痛或松动。
# 食物嵌塞增多。
# 颞下颌关节酸胀、弹响或不适。

处理咬合紊乱需要先找到原因。残根、缺牙、牙周炎和修复问题的处理路径不同。

@@@@@ 唾液 ||| tags=龋齿 ||| 327字
唾液是口腔里的重要防线。它能冲洗食物残渣和细菌，稀释并中和酸，还能提供钙、磷等矿物质，帮助早期脱矿的[[牙釉质]]重新矿化。

唾液保护牙齿主要靠三件事：流量足、缓冲能力强、抗菌成分稳定。口干、唾液少或缓冲能力差时，牙齿暴露在酸里的时间更长，[[龋齿]]风险会上升。

睡眠时唾液分泌减少，所以[[睡前刷牙]]很关键。如果睡前残留食物和牙菌斑，细菌会在唾液保护较弱的时间段持续产酸。

CA6 基因编码的碳酸酐酶 6 与唾液 pH 调节、缓冲能力和口腔菌群有关。部分研究提示，相关基因差异可能影响个体龋齿风险。

@@@@@ 无症状残根 ||| tags=龋齿 牙齿 ||| 334字
无症状残根，是指口腔里残留多年、平时不痛不肿、不明显影响吃饭的[[残根]]。它最容易被忽视，因为“没感觉”会让人误以为“没问题”。

# 牙龈反复起小脓包或有异味。

# 影像显示根尖阴影、骨质破坏或囊性改变。
# 邻牙倾斜、对颌牙伸长或咬合改变。

无症状残根应定期拍片和检查，判断是否有[[根尖病灶]]和保留价值，而不是长期放任。

@@@@@ 早期龋 ||| tags=龋齿 ||| 318字

@@@@@ 根管治疗 ||| tags=牙齿 牙科 牙髓炎 根管手术 ||| 569字
根管治疗，俗称[[抽牙神经]]，核心不是“止痛”本身，也不是普通[[补牙]]，而是把已经感染、发炎或坏死的[[牙髓]]和根管内细菌清理掉，再把根管严密封闭，尽量保住牙根和牙体结构。

[img[根管治疗-保牙总览.png]]

!! 核心逻辑
* 清除感染源：去除发炎、坏死的牙髓组织和根管壁上的细菌碎屑。
* 消毒管道：通过根管预备、冲洗和必要的封药，降低残留感染。
* 封闭根管：用牙胶尖和封闭剂填满根管，减少细菌再次进入。
* 保护牙体：最后补牙、嵌体或牙冠修复，避免牙体继续劈裂。

* [[根管治疗为何不一次搞完？]]：为什么常要 2-4 次就诊。
* [[根管治疗牙片]]：为什么治疗前、中、后都可能拍片。
* [[根管治疗后为什么要做牙冠]]：为什么充填后还要修复保护。

@@@@@ 根管治疗不是补牙 ||| tags=牙齿 牙科 根管治疗 补牙 ||| 331字
根管治疗不是普通补牙。普通补牙主要处理浅层或中层龋坏造成的牙体缺损；[[根管治疗]]处理的是细菌已经进入牙髓或根尖周组织后的感染问题。

[img[根管治疗-原理示意.png]]

!! 区别
* 补牙：去除龋坏牙体，恢复牙齿外形和功能，前提通常是牙髓还可以保留。
* 根管治疗：清除感染或坏死的[[牙髓]]，消毒根管，再用材料严密封闭。
* 后续修复：根管治疗后如果牙体缺损大，还需要补牙、嵌体或牙冠保护。

所以“蛀牙补补就行”只适用于没有伤及牙髓的阶段；一旦出现不可逆牙髓炎、牙髓坏死或根尖周炎，就不是简单补牙能解决。

@@@@@ 根管治疗为何不一次搞完？ ||| tags=牙齿 牙科 根管治疗 ||| 349字
根管治疗通常不是“钻开、抽掉、补上”这么简单。它要先清除感染牙髓和坏死物质，再反复冲洗消毒、评估根管预备质量，最后才能严密充填并做修复保护。

!! 为什么常要分次
* 感染控制需要时间：根管内细菌和坏死碎屑不一定一次就能清干净。
* 需要观察反应：疼痛、渗出、根尖炎症没有稳定时，直接永久封闭风险更高。
* 有时要封药：感染严重时，医生可能在根管内封药 1-2 周。
* 修复要分阶段：根管充填后，还可能需要补牙、取模、做牙冠。

所以常见流程会安排 2-4 次就诊，耗时约 2-3 周；具体次数取决于感染程度、根管复杂度和医生判断。

@@@@@ 根管治疗后为什么要做牙冠 ||| tags=牙齿 牙科 根管治疗 牙冠 ||| 239字
根管治疗后的牙齿常建议做牙冠，是因为牙髓被清除后，牙体失去部分营养来源，颜色可能变暗，剩余牙体也更容易变脆、折断或劈裂。

[img[根管治疗-根管充填封闭.jpg]]

尤其是后牙，本来就要承受较大咬合力；如果牙冠缺损多，只靠补牙材料支撑，长期咀嚼时更容易裂到牙根，严重时只能拔牙。

牙冠的作用可以理解为给治疗后的牙齿加一层保护壳，帮助延长使用寿命。

@@@@@ 根管治疗安全性 ||| tags=牙齿 牙科 根管治疗 ||| 361字
根管治疗步骤多、器械多、技术要求高，但它已经是成熟的保牙治疗方式，也是目前处理很多牙髓病和根尖周病的重要方法。

[img[根管治疗流程示意图.svg]]

根管治疗过程通常会使用局部麻醉。多数情况下，明显疼痛来自牙齿原本的炎症压力，而不是治疗本身。

整理这类内容时要抓住一点：根管治疗的目标不是制造一颗“新牙”，而是在清除感染的前提下尽量保存患牙。成功率受根管复杂度、感染程度、充填质量和后续修复保护影响。

如果牙齿还有保留价值，根管治疗通常比直接拔牙种牙更优先；如果牙根破坏严重或没有修复价值，才需要评估拔除和后续修复。

@@@@@ 根管治疗就诊次数 ||| tags=牙齿 牙科 根管治疗 ||| 318字
根管治疗常见需要 2-4 次就诊，整体可能持续 2-3 周。原因是它不是单次止痛操作，而是一套清创、消毒、充填和修复流程。

[img[根管治疗-开髓释放髓腔压力.jpg]]

!! 常见分次逻辑
* 第一次：开髓、止痛、初步清理感染牙髓。
* 中间治疗：根管预备、冲洗消毒，必要时封药观察。
* 最终治疗：根管充填，确认封闭质量。
* 后续修复：补牙、嵌体或牙冠，保护剩余牙体。

不是次数越少越好，也不是次数越多越严重；关键看根管是否清理干净、感染是否稳定、封闭是否严密。

@@@@@ 根管治疗止痛原理 ||| tags=牙齿 牙科 根管治疗 牙疼 ||| 357字
[[根管治疗]]能缓解牙痛，主要靠两件事：释放密闭髓腔里的压力，并清除持续刺激神经和根尖周组织的感染源。

[img[小牙疼拖成大问题-牙髓受压.jpg]]

牙髓被牙釉质、牙本质等硬组织包在里面。发炎肿胀时，它不像皮肤脓包那样容易向外释放，压力会在髓腔内快速升高，所以会出现自发痛、夜间痛、冷热刺激痛或放射痛。

开髓后，髓腔压力被释放，疼痛常会明显缓解；后续清理、消毒和充填根管，是为了让坏死牙髓和细菌不再持续刺激[[根尖孔]]外的根尖周组织。

[img[根管治疗-开髓释放髓腔压力.jpg]]

所以止痛药只能暂时降低痛感，不能替代根管治疗清除根管内部感染。

@@@@@ 根管治疗步骤 ||| tags=牙齿 牙科 根管治疗 牙髓炎 ||| 592字
[[根管治疗]]通常可以理解为四步：打开、清除、消毒、封闭。先看图，再看每一步会更直观。

[img[根管治疗流程示意图.svg]]

!! 1. 开髓
[img[根管治疗-开髓释放髓腔压力.jpg]]

局部麻醉后从牙冠打开通往髓腔的入口，释放髓腔压力，建立治疗通道。详见[[开髓]]。

!! 2. 拔髓
用细小器械清除感染、发炎或坏死的[[牙髓]]组织，也就是俗称[[抽牙神经]]。详见[[拔髓]]。

!! 3. 根管预备和冲洗消毒
[img[根管治疗-坏死牙髓与脓疮.jpg]]

用根管锉修整管壁，配合冲洗液清除细菌、坏死碎屑和感染物；感染重时可能需要根管内封药观察。详见[[根管预备和冲洗消毒]]。

!! 4. 根管充填和修复
[img[根管治疗-根管充填封闭.jpg]]

用牙胶尖和封闭剂填满根管，再通过补牙、嵌体或牙冠恢复牙体结构。详见[[根管充填]]。

!! 关键点
根管治疗的成败不只看“牙神经有没有抽掉”，更看根管是否清理到位、消毒充分、充填严密，以及后续牙体有没有被妥善保护。

@@@@@ 根管治疗误区 ||| tags=牙齿 牙科 根管治疗 ||| 303字
根管治疗常见误区，主要来自把治疗本身和牙髓感染造成的疼痛混在一起。

[img[根管治疗-原理示意.png]]

!! 三个误区
* 误区一：根管治疗一定很疼。实际治疗会局部麻醉，很多痛感来自原本的牙髓炎症；治疗目标是止痛和清除感染。
* 误区二：牙齿不痛就不用治。[[牙髓坏死]]或慢性根尖炎症可能暂时不痛，但感染仍可能持续破坏牙体和根尖周组织。
* 误区三：做完根管牙就废了。根管后的牙失去牙髓活力，但只要充填严密、修复保护到位、定期检查，仍可以正常使用很久。

@@@@@ 根管治疗适应证 ||| tags=牙齿 牙科 根管治疗 牙髓炎 ||| 356字
根管治疗主要用于牙髓病和根尖周病，尤其是[[牙髓炎]]、[[牙髓坏死]]和各类[[根尖周炎]]。

[img[根管治疗-需要做根管的情况.png]]

!! 常见来源
* [[龋齿]]太深，细菌进入牙髓。
* 牙齿隐裂、外伤或过度磨耗，导致牙髓受损。
* 牙髓已经不可复性损害，无法保留活髓。
* 根管内感染向根尖扩散，出现咬合痛、叩痛或牙龈脓包。
* 自发痛、夜间痛，冷热刺激后疼痛久久不消退。
* 牙齿变暗发黑，即使不痛也提示牙髓可能已经坏死。

核心判断不是“疼不疼”，而是牙髓是否还能保留、感染是否已经进入根管或根尖周组织。

@@@@@ 根面平整 ||| tags=牙周炎 ||| 279字

@@@@@ 植骨粉后注意事项 ||| tags=种牙 骨粉 ||| 521字
植骨粉后的护理重点是保护创口、减少感染风险、避免[[骨粉]]被冲出，并给新骨形成留下稳定环境。具体医嘱应以手术医生要求为准，手术流程可参考[[植骨粉手术怎么做？]]。

术后可以做：

# 前 24 至 48 小时按医嘱冷敷，帮助减轻肿胀。
# 选择软食、温凉饮食，避免用手术侧咀嚼。
# 按医嘱服用止痛药、抗生素或漱口液，不自行停药或加药。
# 保持口腔清洁，但刷牙和漱口动作要轻，避免直接碰撞手术区。
# 睡觉时适当抬高头部，有助于减轻肿胀。

术后应避免：

# 用力漱口、吐口水、吸吮伤口或频繁拨弄创口。
# 吸烟、电子烟和饮酒，因为它们会增加愈合不良和感染风险。
# 短期内剧烈运动、搬重物或熬夜。
# 吃太烫、太硬、辛辣或容易卡进创口的食物。
# 自行抠掉血凝块、缝线或看起来像“沙粒”的少量骨粉颗粒。

少量骨粉颗粒在术后早期从创口边缘排出不一定代表失败；如果骨粉大量脱落、疼痛加重、肿胀不退或出现流脓，应及时复诊。

@@@@@ 植骨粉失败有什么表现？ ||| tags=种牙 骨粉 ||| 506字
植骨粉后有轻度疼痛、肿胀、淤青和少量渗血，通常属于早期恢复反应。真正需要警惕的是症状持续加重，或出现感染、创口裂开、骨粉大量流失等异常表现。常规护理可参考[[植骨粉后注意事项]]。

需要尽快联系医生的情况：

# 疼痛越来越重，或止痛药效果明显不佳。
# 肿胀在数天后仍明显加重，或伴随面部发热、跳痛。
# 创口有脓液、明显异味、持续出血或牙龈裂开。
# 发热，尤其是体温达到 38.3°C 左右或更高。
# 骨粉像沙粒一样大量流出，或感觉填骨区域明显塌陷。
# 术区麻木、刺痛持续不缓解，或咬合、张口明显异常。
# 后续影像检查显示骨量没有达到预期，无法按计划进行[[种植体]]植入。

影响植骨成功的常见因素包括吸烟或电子烟、口腔卫生差、未控制的[[牙周炎]]、糖尿病血糖控制不佳、局部感染、过早用手术侧咀嚼，以及没有按医嘱复诊。

植骨粉失败不一定意味着不能[[种牙]]，但通常需要先找出原因，再决定是否清创、重新植骨、延长愈合时间或调整修复方案。

@@@@@ 植骨粉手术怎么做？ ||| tags=种牙 骨粉 ||| 563字
植骨粉属于骨增量思路，目的是在[[牙槽骨]]高度或厚度不足时，为后续[[种牙]]创造更稳定的骨基础。具体方式要根据 CBCT 影像、缺骨范围和是否同时植入[[种植体]]决定。

常见流程：

# ''术前评估''：医生通过口腔检查和三维影像判断缺骨位置、骨高度、骨宽度，以及是否接近[[上颌窦]]或神经管。
# ''麻醉和切开''：通常在局部麻醉下切开牙龈，暴露需要补骨的骨面。
# ''清创和预备骨面''：清除炎症组织、肉芽组织或不利于愈合的软组织，让骨粉接触稳定的骨床。
# ''填入骨粉''：把[[骨粉]]放入骨缺损区域，必要时与自体骨或其他骨替代材料混合。
# ''覆盖骨膜''：用[[骨膜]]覆盖骨粉，帮助固定骨粉、阻挡软组织长入，并为新骨生成提供稳定环境。
# ''缝合等待愈合''：关闭创口后等待骨粉与自身骨组织融合。多数情况下，骨成熟后再安排种植；少数条件合适时可同期植入种植体。等待时间可参考[[植骨粉后多久能种牙？]]。

如果是[[上颌]]后牙区骨高度不足，可能需要配合[[上颌窦提升]]。如果缺骨范围很大，可能需要更复杂的骨块移植或分阶段治疗。

@@@@@ 残根内部感染 ||| tags=龋齿 牙齿 ||| 233字
残根内部感染，是[[烂牙根]]最容易被低估的问题。牙冠烂坏后，残留牙根内部可能存在松软[[牙本质]]、空洞、裂缝和坏死组织，形成牙刷无法进入的细菌滞留区。

@@@@@ 残根拔除 ||| tags=龋齿 牙齿 ||| 387字
残根拔除，是对没有保留价值、感染风险明显或无法修复的[[残根]]进行拔除和病灶清理。它的目的不是“拔掉一颗牙”这么简单，而是清除长期[[口腔感染源]]，保护邻牙、牙槽骨和后续修复条件。

@@@@@ 牙周炎为什么不能靠吃药解决？ ||| tags=牙周炎 ||| 855字
!! 一个普遍的误区

很多人以为[[牙周炎]]就是“牙龈发炎”，吃点消炎药、止痛药，或者用漱口水压一压，炎症就会好。

这个理解只对了一小部分：药物可能暂时减轻红肿、疼痛、出血或口臭，但解决不了牙周炎真正的根源——牙齿表面和牙龈下方长期堆积的[[牙菌斑生物膜]]与[[牙结石]]。

!! 为什么吃药不够

# 牙周炎的病灶在牙龈下面。细菌、毒素和牙石常藏在[[深牙周袋]]里，普通刷牙和吃药都不能把它们机械清除。
# [[牙结石]]像硬化的细菌支架，会持续吸附菌斑并刺激牙周组织。它不能靠药物溶掉，需要专业洁治或[[龈下刮治]]去除。
# 抗生素主要影响游离细菌，对成熟的牙菌斑生物膜穿透有限。即使短期压低细菌数量，如果牙石和牙周袋还在，炎症很容易反复。
# 牙周炎已经造成的[[牙槽骨]]吸收不会因为吃药自动长回去。治疗目标是控制炎症、阻止继续破坏，并进入长期[[牙周维护]]。
# 乱用抗生素还可能带来耐药、胃肠反应、过敏等风险，所以不能把它当作牙周炎的常规主治疗。

!! 正确治疗逻辑

牙周炎治疗的核心不是“把火压下去”，而是把让火一直烧的燃料清掉。

# 基础控制：学会有效刷牙、邻面清洁，减少新的牙菌斑形成。
# 专业清除：通过洁牙、[[龈下刮治]]和[[根面平整]]清除牙龈上方和牙龈下方的菌斑、牙石和毒素。
# 复查评估：观察牙龈出血、牙周袋深度、牙齿松动和影像中的骨吸收变化。
# 长期维护：按风险定期复诊，防止牙菌斑和牙结石重新堆积。
# 药物辅助：只有在特定感染、急性发作、重度或复杂病例中，医生才会考虑局部或全身用药，且通常是配合机械治疗使用。

所以，牙周炎不能只靠吃药解决。药物像临时降温，真正改变病程的是清除菌斑牙石、控制牙周袋、维护清洁习惯和定期复查。

@@@@@ 牙槽骨 ||| tags=种牙 ||| 418字
牙槽骨就是种植体的“地基”，地基悄悄流失，后期就会出现牙龈红肿、溢脓、种植体松动，严重时种植牙只能取出更换。

@@@@@ 牙槽骨吸收 ||| tags=牙齿 牙周炎 种牙 ||| 312字
牙槽骨吸收，是指支持牙齿或未来种植体的[[牙槽骨]]发生减少。它可以由[[牙周炎]]、缺牙后缺乏咀嚼刺激、长期[[根尖病灶]]、囊肿或局部感染等因素造成。

牙槽骨吸收的后果：

# 降低牙齿保留机会。
# 影响邻牙支持条件。
# 增加拔牙后的修复难度。
# 可能需要[[骨粉]]、植骨或其他骨增量手段后才能[[种牙]]。

@@@@@ 牙菌斑生物膜 ||| tags=龋齿 牙周炎 从浅龋到深龋到拔牙：牙周炎是如何加快龋齿的发展速度的 ||| 484字
牙菌斑生物膜是牙齿表面由细菌、代谢产物和黏性基质形成的微生态结构。它不是简单的一层“脏东西”，而是能长期黏附在牙面和龈缘附近的细菌群落。

在[[龋齿]]中，牙菌斑里的产酸细菌利用糖和可发酵碳水化合物产酸，使[[牙釉质]]和牙本质脱矿。

在[[牙周炎]]中，龈缘和龈下牙菌斑会刺激宿主免疫炎症反应，导致牙周膜、牙槽骨等支持组织逐渐破坏。

因此，控制牙菌斑生物膜是同时预防龋齿和牙周炎的共同基础，包括有效刷牙、邻面清洁、定期洁治和风险评估。

当牙菌斑长期堆积并矿化，会形成[[牙结石]]。牙结石会让菌斑更容易停留，也是[[牙周炎为什么不能靠吃药解决？]]的关键原因之一。

@@@@@ 牙釉质 ||| tags=龋齿 ||| 381字
牙釉质是牙齿最外层的坚硬组织，主要作用是保护内部的牙本质和牙神经。它虽然很硬，但经不起长期、频繁的酸攻击；当细菌分解糖和淀粉产酸时，牙釉质会逐渐脱矿，最终形成[[龋齿]]。

牙釉质每天都可能在[[牙齿脱矿]]和[[牙齿再矿化]]之间反复拉扯。真正危险的是脱矿发生太频繁、再矿化时间不足。

牙釉质的厚度、密度和矿化质量受发育过程和遗传因素影响。AMELX、AMBN、ENAM、TUFT1 等基因参与牙釉质形成，因此有些人天生牙釉质更耐酸，有些人则更容易出现脱矿和早期龋。

保护牙釉质的关键不是把牙刷得更用力，而是减少酸攻击频率，并用[[氟化物]]促进再矿化。频繁吃糖、喝含糖或酸性饮料，会让牙釉质长期处于失矿状态。

@@@@@ 牙齿基础解剖 ||| tags=牙齿 牙科 牙髓 根管治疗 ||| 407字
理解[[根管治疗]]，要先知道牙齿不是一整块实心硬物，而是外硬内软的结构。

[img[根管治疗-牙齿基础解剖.jpg]]

!! 从外到内
* [[牙釉质]]：最外层硬壳，主要负责抵抗磨耗和酸攻击。
* [[牙本质]]：牙齿主体，位于牙釉质下面，内部有细小管道，刺激可传到牙髓。
* 髓腔和根管：牙齿内部的封闭空腔，冠部叫髓腔，牙根内的细长管道叫根管。
* [[牙髓]]：位于髓腔和根管内，包含血管、神经和结缔组织。

@@@@@ 牙齿窝沟 ||| tags=龋齿 ||| 252字

@@@@@ 牙齿脱矿 ||| tags=龋齿 ||| 392字
牙齿脱矿是指酸性环境使[[牙釉质]]或牙本质中的矿物质溶解流失。它是[[龋齿]]形成的早期关键步骤。

@@@@@ 牙齿脱矿怎么办？ ||| tags=龋齿 ||| 595字

# 白色粉笔样、表面完整：尽快做再矿化管理，有机会控制。
# 发黄、发褐、发黑，或表面粗糙：尽快检查，可能已进入龋损阶段。
# 已经有洞、塞东西、冷热痛、咬合痛：通常不能只靠再矿化，需要牙医处理。

致龋菌是指更容易参与[[龋齿]]形成的一类口腔细菌。它们不会直接“啃牙”，而是利用糖和可发酵碳水化合物产酸，使[[牙釉质]]和牙本质发生[[牙齿脱矿]]。

常被提到的致龋相关细菌包括：

# 变形链球菌：黏附力强，容易在牙面形成[[牙菌斑生物膜]]，并利用糖持续产酸。
# 乳酸杆菌：耐酸能力强，常参与龋损进一步加深的过程。
# 放线菌：常与根面环境相关，在[[根面龋]]中更常被提到。

致龋菌真正危险的地方，不是单个细菌有多强，而是它们形成生物膜后能长期停留在牙面。漱口难以冲掉成熟菌斑，核心仍然是刷牙、牙线和定期检查。

@@@@@ 骨粉有哪些类型？ ||| tags=种牙 骨粉 ||| 555字
[[骨粉]]不是单一材料，而是一类用于补充[[牙槽骨]]骨量、引导新骨形成的骨移植或骨替代材料。临床会根据骨缺损范围、感染控制、全身健康状况和后续[[种植体]]计划来选择。

常见类型：

# ''自体骨''：取自患者自身，生物活性较好，排异风险低；缺点是需要额外取骨区域，创伤和术后不适可能增加。
# ''异体骨''：来自他人捐献骨，经处理后使用；优点是避免患者自身取骨，常用于中小范围骨缺损。
# ''异种骨''：来源于动物骨，如小牛骨，处理后保留支架结构，常用于维持骨量和骨形态。
# ''人工骨''：由羟基磷灰石、β-磷酸三钙等生物陶瓷或合成材料制成，主要提供骨生长的支撑框架。
# ''混合骨粉''：严重骨缺损时，医生可能把自体骨与异种骨或人工骨混合使用，兼顾骨生成能力和体积稳定性。

骨粉常与[[骨膜]]配合使用：骨粉提供新骨生长的“框架”，骨膜覆盖在表面，帮助隔离软组织、固定骨粉并引导骨组织形成。

选择哪种材料不能只看价格，还要看缺骨位置、骨量缺损程度、是否靠近[[上颌窦]]、是否存在[[牙周炎]]或感染风险，以及患者能否接受取自体骨。

@@@@@ 龋齿和牙周炎的关系 ||| tags=龋齿 牙周炎 从浅龋到深龋到拔牙：牙周炎是如何加快龋齿的发展速度的 ||| 474字
[[龋齿]]和[[牙周炎]]不是两个完全孤立的疾病。它们都与[[牙菌斑生物膜]]有关，只是破坏的主要部位不同：龋齿主要破坏牙体硬组织，牙周炎主要破坏牙龈、牙周膜和[[牙槽骨]]等支持组织。

@@@@@ 龋齿形成机制 ||| tags=龋齿 ||| 459字
龋齿形成不是“虫子把牙吃掉”，而是[[致龋菌]]、食物、时间和宿主共同作用的慢性过程。

可以理解为四个条件：

# 细菌：[[致龋菌]]黏附在牙面，形成[[牙菌斑生物膜]]，并持续产酸。
# 食物：糖和可发酵碳水化合物为细菌提供燃料，尤其是频繁摄入甜食、饼干、含糖饮料和黏性淀粉类食物。
# 时间：每次进食后，牙菌斑局部 pH 会下降，牙齿会经历一段酸攻击。频繁进食会让[[牙齿脱矿]]时间变长。
# 宿主：[[牙釉质]]矿化程度、[[牙齿窝沟]]深浅、牙齿排列、[[唾液]]流量和缓冲能力，都会影响龋齿风险。

如果脱矿大于[[牙齿再矿化]]，早期白垩色改变会逐渐发展为龋洞；如果及时清洁、减少进食频率并使用[[氟化物]]，早期脱矿仍有机会被控制。

@@@@@ 龋齿易感性 ||| tags=龋齿 为什么有人“天生耐蛀”，有人天天刷牙还是满口蛀牙？ ||| 468字
龋齿易感性指一个人天生或后天更容易发生[[龋齿]]的倾向。它不是单纯由“刷牙懒不懒”决定，而是[[牙釉质]]质量、[[牙齿窝沟]]形态、[[唾液]]保护能力、[[口腔菌群]]组成、饮食频率和清洁习惯共同作用的结果。

可以把龋齿理解成一场长期攻防：细菌和糖产生酸，酸让牙釉质脱矿；唾液、氟化物和良好清洁则帮助中和酸、清除残渣、促进再矿化。任何一环弱一点，蛀牙风险都会升高。

遗传研究常用“遗传度”描述群体中龋齿差异有多少可由遗传因素解释。这个数字不能理解成“某个人的蛀牙有一半由基因决定”，而是说明同样生活习惯下，不同人的起点确实可能不同。

遗传因素不需要拆成独立条目，只需理解为一组背景变量：AMELX、AMBN、ENAM、TUFT1 等可能影响[[牙釉质]]形成；CA6 可能影响[[唾液]]缓冲能力；AMY1 和 FUT2 可能影响[[口腔菌群]]环境。这些都只是风险背景，不是命运。

@@@@@ 龋齿高风险预防 ||| tags=龋齿 为什么有人“天生耐蛀”，有人天天刷牙还是满口蛀牙？ ||| 644字
龋齿高风险人群不是简单地“再刷认真一点”就够了，而是要把风险管理做得更精细：更早发现、更少酸攻击、更强再矿化、更少清洁死角。

可以重点做：

# 定期看牙医。别人一年一次，高风险人群可能需要半年一次，甚至按牙医建议更频繁复查。
# 控制[[吃糖频率]]。少量多次吃糖或慢慢喝含糖饮料，会让牙齿长期处在酸攻击里。
# 使用[[氟化物]]。含氟牙膏是基础，反复蛀牙者可咨询牙医是否需要涂氟或处方氟化物。
# 处理深[[牙齿窝沟]]。窝沟很深的人可评估[[窝沟封闭]]。
# 关注[[唾液]]问题。长期口干、服药导致口干、睡觉张口呼吸等，都会削弱自洁和缓冲能力。
# 早期处理白斑和浅龋。早期脱矿阶段还有机会通过再矿化和微创治疗控制，不要等到明显蛀洞才处理。
# 做好[[睡前刷牙]]和[[牙线]]清洁，减少夜间和邻面长期残留的菌斑。
# 发现[[牙齿白斑]]或怀疑[[牙齿脱矿]]时，尽快按[[牙齿脱矿怎么办？]]处理，不要等到成洞。

基因给的是起点，不是终点。知道自己属于高风险，更重要的是把预防频率和强度调到适合自己的水平。
