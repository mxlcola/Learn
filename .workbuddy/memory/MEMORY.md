### 脚本（scripts/）
- `lint_cards.py [标签...]`：全库体检（缺概括/空条目/小标题过多/正文过长/碎片/悬空链接）。
- `extract_summary.py`：从正文首段提取现成概括（--dry-run 先预演）。
- `export_cards_json.py <输出.json> <标题...>`：按标题把 .tid 导出为批量导入用 JSON 数组；
  加 `--from-map <地图标题>` 可从章节地图表格行的双链自动收集标题（地图卡排第一），整本书一次导出。
- `refine_evergreen_cards.py`：2026-11-06 旧卡**改名 + 反链同步**脚本，自带 28 组标题 MAP 与 SOURCE，
  `--dry-run` / `--apply`；含全库双链与头部字段替换、系统临时目录回退快照。
  ⚠️ 其中的 `to_prose()` 段落化已被用户否决，**不要再运行 `--apply`**（会重新压掉分点样式）；
  改名映射表仍可复用（restore 脚本会读取它）。
- `restore_bullet_style.py`：从 `%TEMP%/evergreen_refine_20261106/all_tiddlers_before.json` 快照
  恢复 365 张卡的分点样式并做零损失精简，`--dry-run` / `--apply`；幂等（每次从快照重建），
  含双链占位保护（精简规则绝不改写 `[[…]]` 内部文字）、语境词修正重放、旧标题反链同步。
  保留改名/source/关联行成果。
- `normalize_tooth.py`、`archive_conflicts.py`、`find_dup_titles.py` 等域脚本可复用其解析写法。
- 解析 .tid 头部要用 `re.match(r'(.*?)\r?\n\r?\n', raw, re.S)` 后取 **m.group(1)**，不能用 m.start()。
